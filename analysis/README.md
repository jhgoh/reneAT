# 프롬프트 분석 `analysis/`

런 종류와 세팅마다 보는 변수가 다르고, 그 결과로 결론을 내려 정식 세팅이나 보정값을 정하는 분석을 모아 둡니다.
모든 런에 똑같이 만드는 그림은 DQM(`python/dqm.py`)에 두고, 여기에는 넣지 않습니다. 구분은 `doc/dqm_plan.md` 2절을 따릅니다.

| 디렉토리 | 런 | 정하는 것 | 상태 |
|---|---|---|---|
| `led/` | LED(HV 스캔, SPE 런) | PMT gain, 운전 HV gain | `gain.py` |
| `source/` | 선원 런 | 에너지 척도, 분해능, 위치 응답 | 3–5단계에서 추가 |
| `veto/` | veto 테스트 런 | 패널 효율·문턱, 채널 맵 | 8단계에서 추가 |
| `laser/` | 레이저 런 | 선형성, 포화 | 보류(측정 조건 관리가 어려웠던 데이터. 새로 측정하면 추가) |

## 규칙
- `source reneAT/setup.sh` 뒤에 실행합니다(`python/`의 `prd`, `runsheet`, `qsum` 등을 씀).
- 런 목록은 run sheet(`runsheet.RunSheet`)의 데이터셋과 종류로 고르고, 창 설정과 런 목록은 인자로 받습니다.
- 출력 디렉토리는 `--out`으로 받습니다. 결론 숫자는 `<out>/*.json`으로 남겨서 DQM과 MC(renesim)가 기준값으로 읽을 수 있게 합니다.
- 결과는 이슈 #6(커미셔닝)의 해당 항목에 적습니다.
